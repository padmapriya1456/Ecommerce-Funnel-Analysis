# E-Commerce Funnel & Conversion Performance Analysis

## Project Overview
This project analyzes customer behavior in an e-commerce platform using funnel analysis techniques.

## Funnel Stages
- Product Views
- Add to Cart
- Purchases

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboarding

## Key Insights
- High drop-off before purchase stage
- Some categories generated better conversions
- Customer activity varied over time

## Recommendations
- Improve checkout process
- Reduce cart abandonment
- Focus on high-performing categories

## Dashboard Features
- KPI Cards
- Funnel Analysis
- Category Performance
- Time Trend Analysis
